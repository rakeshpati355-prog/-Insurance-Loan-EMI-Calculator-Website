How It Works

This page demonstrates a basic EMI and insurance premium calculator using only HTML, CSS, and JavaScript.

  • Loan EMI uses the standard reducing‑balance formula. [52][55][58][61]
  • Insurance premium uses a simplified rule‑based model for demonstration. [57][60][66]
  • All calculations happen in your browser; no data is sent to any server.

Formulas Used

Loan EMI:
EMI = P × r × (1 + r)ⁿ ÷ [(1 + r)ⁿ − 1]
P = principal, r = monthly interest rate, n = total months. [52][55][58][61][64]

Insurance (simplified):
Base premium ≈ Sum Assured × baseRate% × (age / termYears) × riderFactor. [57][60][66]
